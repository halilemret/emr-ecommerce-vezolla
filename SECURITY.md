# Security Policy

The Vezolla E-Commerce team takes security issues seriously and welcomes responsible reporting from the security community.

---

## Supported Versions

Only the latest release on the `main` branch receives active security updates:

| Version | Supported          |
| :---    | :---               |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities via public GitHub issues.**

If you believe you have discovered a vulnerability, please disclose it responsibly:

1. **Email the Maintainer**: Send an email describing the vulnerability to the repository maintainer (via GitHub profile contact or private security advisory).
2. **Include Reproduction Steps**: Provide a detailed description of the vulnerability, including:
   - Affected file, component, or API endpoint
   - Step-by-step reproduction instructions or proof-of-concept (PoC)
   - Potential impact of the issue
   - Any suggested mitigations or patches

---

## Response Timeline

- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Assessment & Fix**: We will work to investigate, reproduce, and provide a patch within 7 to 14 business days depending on complexity.
- **Public Disclosure**: Once a patch is released and validated, a security notice will be published acknowledging the reporter (if desired).
